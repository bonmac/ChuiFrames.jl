### p4-groupby tasks
1. Typed keys + open-addressing table (`hashagg.jl`), canonicalisation tests (±0, NaN, missing,
   DictColumn with ±0 entries, Tuple keys).
2. `radix_partition` (stable) + property test.
3. `build_gindex` on the new keys (eager group_by faster; all existing tests pass).
4. Hash-aggregate operator: simple-aggregate recogniser, typed accumulators, protocol fallback,
   specialised == protocol tests; eager `summarise` fast path.
5. Lazy hash-aggregate sink in `execute.jl` (partial per contiguous range → merge in order →
   final → sort by keys), adaptive radix switch (forced at 4 groups in tests), `explain` lines.
6. Grouped-window sink (parallel over contiguous group ranges, scatter).
7. lazy == eager property tests for grouped sinks at -t 1 / -t 4.

### p4-join tasks
1. `JoinStep` + verbs + `by` parsing + output schema/naming (eager), unit tests vs dplyr examples.
2. Hash build/probe (`join.jl`), broadcast and partitioned, `na_matches`, `multiple`,
   `unmatched`, right/full tail.
3. Oracle nested-loop join; differential vs dplyr (Rscript) and DuckDB/Polars (uv).
4. `JoinNode` (tree), tree-aware passes, filter pushdown through joins, projection per side.
5. Lowering to `ProbeStep`, `collect`/`reference` on trees, `explain` tree printing (linear plans
   print as before), snapshots in `test/snapshots/lazy_join/`.
6. lazy == eager property tests for joins at -t 1 / -t 4, each strategy forced.

### p4-codegen tasks
1. Measure (1.13, 1.10): compile time per new shape vs depth, per-row interpreter vs compiled on
   1–10-step stages, multi-column and string stages; write `docs/research/codegen-phase4.md`.
2. Closure-composed fused kernels with typed outputs, shape cache, threshold, fallbacks.
3. Property test: compiled == interpreter, exception types on throwing stages.
4. `_explain_kernel` line.
