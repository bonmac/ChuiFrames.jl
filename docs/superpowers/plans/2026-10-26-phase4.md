### p4-groupby2 tasks (phase B)

   `_keypair_compare_type(Sx, Sy) -> Union{Nothing, Type}` in `src/engine/hashagg.jl`:
   `Union{}` side → the other type; `Sx === Sy` → `Sx`; both `<: AbstractString` → `String`;

   rejected `Date`/`DateTime`, `Int64`/`UInt64`, `Int8`/`UInt8` and string/number pairs, and the
   `isequal` ⇒ `keyhash` property after conversion to the compare type, with values at the 2⁵³
   boundary. The existing assertion that `Int64`/`Float64` is rejected is changed (it is the
   user's ★ K4 decision, not a weakened test).

   `n=10` budget row (ADR-0022 rule 3).

   phase 3 (`===` test). Simple-aggregate recogniser (spec §2.1, via `_aggregator`).
   - Typed accumulators: `add_sum` type for `Sum` **only**; `Mean` is `(typeof(float(x)), Int)`

     MapM/ReduceM.
